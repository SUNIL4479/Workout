# FitiFi React Native Appium 2.x Automation Framework

Enterprise-grade End-to-End (E2E) mobile automation framework built with Appium 2.x, WebdriverIO, Mocha, Chai, Mochawesome, Winston Logger, and ExcelJS.

## Features
- **Appium 2.x & UiAutomator2 Support**: Built for modern React Native Android application testing.
- **React Native Locators**: Native support for `Accessibility ID`, `ValueKey`, `Semantics Label`, and `Text`.
- **Smart AI Testing Capability**: AI module automatically discovers screen hierarchy and generates test scenarios.
- **Gesture Utilities**: Tap, Double Tap, Long Press, Swipe, Drag & Drop.
- **Reporting**: Excel Report (`React Native_E2E_Report.xlsx`) with 4 distinct analytical sheets + Mochawesome HTML report.
- **CI/CD Integration**: Fully integrated with GitHub Actions (`.github/workflows/react-native-appium.yml`).

## Quick Start
```bash
cd appium-tests
npm install
npm test
```
